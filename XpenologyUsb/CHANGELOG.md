# 변경 기록

## 0.5.0

- 기본 창을 680×820에서 480×640으로 줄이고 최소 420×560에서 작업할 수 있도록 화면을 정리했습니다.
- 온라인 로더 버전 선택과 파일명, 다운로드 크기, 발행자 체크섬 제공 여부 표시를 추가했습니다.
- 로컬 IMG, gzip, ZIP 이미지 굽기를 추가했습니다. 대상 접근 전에 압축을 완전히 풀고 부트 서명을 검사합니다.
- 최대 4 GiB의 다운로드 캐시, 캐시 끄기와 비우기를 추가했습니다. 재사용 시 파일 해시를 검사합니다.
- 작업 중 종료 확인과 취소 후 정리 완료를 기다리는 종료 흐름을 추가했습니다.
- 안전 제거 전에 처음 선택한 USB의 신원을 다시 확인합니다.
- 오류 원인과 대상 변경 여부를 분리하고 진단 정보 복사 기능을 추가했습니다.
- USB 복제도 선택 후 다음 버튼으로 진행하며, 완료 화면에서 검증 여부를 명확히 구분합니다.
- 한국어/영어, 밝은/어두운 테마와 두 창 크기에 대한 화면·접근성 테스트를 확대했습니다.
- 개발 의존성 source-map-js의 보안 패치를 적용했습니다.

실제 USB 컨트롤러별 동작, 안전 제거, Defender 반응과 부팅은 실물 확인이 필요합니다.
자동화된 단위·브라우저·가상 디스크 테스트가 실물 검증을 대신하지 않습니다.
